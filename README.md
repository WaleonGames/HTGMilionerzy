## HTGMilionerzy

HTGMilionerzy to projekt odwzorowujący rozwiązania znane z telewizyjnego programu „Milionerzy” w Polsce. Projekt został zainspirowany przez [TheMillionaireGame](https://github.com/Macronair/TheMillionaireGame).

Na tej podstawie zacząłem tworzyć ulepszoną i bardziej uniwersalną wersję, która będzie umożliwiać korzystanie z programu w różnych miejscach bez potrzeby instalowania niepotrzebnych dodatkowych wtyczek lub programów.

## Co oferuje?

- Obsługę programu w języku polskim.
- System zarządzania bazą pytań i przebiegiem rozgrywki.
- Panel sterowania umożliwiający prowadzenie gry.
- Obsługę jednego lub wielu ekranów z możliwością konfiguracji monitora i rozdzielczości.
- Możliwość rozdzielenia ekranu gry i panelu sterowania na osobne okna.
- Rozbudowane ustawienia programu i rozgrywki.
- Konfigurowalny wygląd interfejsu oraz ekranu gry.
- System animacji wybranych elementów rozgrywki.
- Konfigurowalne drzewko nagród.
- Rozbudowany i konfigurowalny system skrótów klawiszowych.
- Wbudowany pomocnik prezentujący dostępne skróty klawiszowe.
- Lokalne przechowywanie pytań, konfiguracji i pozostałych danych programu.
- Zabezpieczenia przed uruchomieniem rozgrywki przy nieprawidłowej lub niekompletnej konfiguracji.

## Co planujemy dodać?

- Rozbudowane zarządzanie dźwiękiem oraz dalszy rozwój grafiki i wyglądu gry.
- Rozbudowaną konfigurację oraz możliwość udostępniania ekranu gry na inny monitor lub urządzenie niezależnie od połączenia kablowego.
- Obsługę przez stronę internetową jako panel sterowania lub interfejs dla osoby grającej.
- Rozbudowane koła ratunkowe, również z myślą o rozgrywkach z mniejszą liczbą osób.
- Oraz wiele innych funkcji.

## Skróty Klawiatury

**Ogólne**
- Ctrl + S - Pokaż/ukryj pomocnik skrótów
- Ctrl + H - Otwórz panel główny
- Ctrl + G - Rozpocznij grę
- Ctrl + Q - Wyjdź z programu
- Ctrl + P - Baza pytań
- Ctrl + Przecinek - Ustawienia
- F5 - Odśwież
- Ctrl + F5 - Wymuś odświeżenie
- F11 - Pełny ekran
- F12 - DevTools

**Gra**
- G + B - Pasek boczny
- G + A - Panel sterowania
- G + M - Główny ekran
- G + P - Pokaż pytanie
- G + O - Pokaż odpowiedzi
- G + [1-4] - Odpowiedz A-D
- G + Enter - Potwierdź odpowiedź
- G + N - Nastepne pytanie
- G + E - Zakończ grę

**Pytanie**
- P + A - Dodaj pytanie
- P + E - Edytuj pytanie
- P + R - Usuń pytanie
- P + D - Aktywne/nieaktywne pytanie (działa tylko przy konfiguracji/dodawania pytania)
- P + Q + [1-4] - Ustaw poprawną odpowiedź A-D
- P + L + [1-9] + [0-2] - Ustaw poziom 1-12

**Ustawienia**
- U + O - Otwórdz zakładkę Ogólne
- U + E - Otwórdz zakładkę Ekran
- U + D - Otwórdz zakładkę Dźwięk
- U + N - Otwórdz zakładkę Drzewko nagród
- U + W - Otwórdz zakładkę Wygląd
- U + Z - Otwórdz zakładkę Zapisy danych
- U + S - Otwórdz zakładkę Skróty
- U + U - Zapisz ustawienia
- U + P - Przywróć ustawienia domyślne
- U + K - Otwórz paletę Kolorów

## Wymagania systemowe

> Wymagania są wstępne i mogą ulec zmianie wraz z rozwojem programu.

### Sprzęt

- **CPU, RAM i GPU:** wymagania nie zostały jeszcze określone.
- **Rozdzielczość:** minimum 1280×720 (HD), zalecane 1920×1080 (Full HD) lub wyższa.
- **Monitory:** minimum 1, zalecane 2 lub więcej.

### Oprogramowanie

- **Windows:** Windows 10 lub nowszy.
- **Ubuntu:** Ubuntu 20.04 LTS lub nowszy.
- **Debian:** wspierane wersje.
- **Node.js:** v22.23.1 — **wymaganie tymczasowe**.

### Dodatkowe informacje

Wymagania dotyczące procesora, pamięci RAM i karty graficznej zostaną dokładniej określone po przeprowadzeniu testów na różnych konfiguracjach sprzętowych.
