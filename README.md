## HTGMilionerzy 
To jest projekt z tych typu odwzorowanie się na istniejących telewizyjnych programów w Polsce Milionerzy czy programy który zostało stworzone ten program został zainspirowany przez [TheMillionaireGames](https://github.com/Macronair/TheMillionaireGame). I z tego powodu zacząłem tworzyć ulepszą wersje który będzie umożliwiać używanie w kilku miejscach bez nie potrzebnych doinstalowywanie wtyczek/programów.

## Co takie ofertuje?
- Obsługe tylko języku Polskiego.
- Aktualnie jest dodane wyłącznie na jeden monitor lub dwa monitory czyli sterowanie + menu gry albo oddzielnie przez funkcje rozdzielenia w panelu sterowania.

## Co będzie planowane dodanie?
- Dodanie rozbudowane zarządzanie dźwiękem, grafiki lub wyglądem gry milionerów.
- Dodanie rozbudowane konfiguracje oraz obsługie przez opcje udostępienie ekranu na inny monitor nie zaleźnie od kabla.
- Dodanie obsługę przez stronę internetową jako panel sterowania lub osobę grająca.
- Dodanie rozbudowanych kół ratunkowych w przypadku mniejszym gromadzeniu osób.
- oraz wiele innych rzeczy
